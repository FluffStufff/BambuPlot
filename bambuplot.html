When should I use simple line text?

Use this when you want quick, pen-like lettering. Each character is drawn with simple strokes, so it uses fewer pen moves than an outlined font. Lowercase is shown as capitals.

How does my handwriting get used?

Draw the letters you want BambuPlot to use. Missing characters fall back to the built-in line font. Save several versions of a letter if you want repeated letters to vary; Randomness adds small position changes.

How do I draw my alphabet?

Pick a character, draw it, then choose Save & next letter. Start a new stroke for separate marks such as the dot on an “i”. You can save up to five versions of each character, and BambuPlot keeps them in this browser.

Which font plot style should I use?

Use Shape-following fill when you want bold or decorative letters to look filled. BambuPlot adds repeated inner lines that follow the shape of each letter.

Shapes or freehand?

Choose a shape when you want clean geometry. Rectangle can stretch wider or taller; the other shapes keep their proportions. Choose Freehand when you want to sketch directly on the bed with the mouse or pointer.

Which vector-image style should I use?

Choose Outline only for logos and line art when you just want the edges. If a simple stroke imports as two outlines, try Single line. Use Shape-following, Light or Straight-line fill when you want filled areas to contain pen strokes.

How does split-by-colour work?

Turn this on when you want to draw a flat-colour SVG with different pens. Each colour becomes its own linked layer, so you can assign pen colours without losing the artwork’s alignment.

Higher Fill Density adds more interior lines and more ink.

How is a model turned into a plot?

BambuPlot flattens the side you selected into a 2D drawing. Choose Outline, Shape-following fill, Light fill or Straight-line fill just like other artwork. The result is an orthographic view, with no perspective.

Project or profile: what's the difference?

Project = this artwork. Save one when you want to reopen the same layers, positions and layout later. Profile = your setup. Save one when you want a backup of your printer, drawing tool, theme and handwriting settings, or want to move them to another browser.

Plot order runs top → bottom. Drag layers to change what plots first and last. Later layers draw over earlier ones, and BambuPlot only pauses when the pen colour changes. Groups keep artwork aligned while moving or resizing, but their layers can still be reordered.

How do the alignment crosses work?

Use this when you want help placing a sheet accurately. BambuPlot first draws four small corner marks on backing paper, then moves the head to the back so you can place your material on those marks and secure it with magnets.

How far down should I mount the pen?

Mount the pen so its tip just touches the material when the nozzle is at Draw Z. For thin paper and Draw Z = 0.5 mm, start with the tip about 0.5 mm below the nozzle. Aim for gentle contact, not pressure. Lift Z is how high the pen rises between strokes.

How does variable pressure work?

Use this with Pencil, Crayon, Chalk or a flexible custom tool when you want light and dark strokes. BambuPlot presses farther down for darker areas by making small Z changes below Draw Z. Start with a small range on scrap material. BambuPlot never commands pressure below Z0.05, and you should only use this with a holder and tool that can flex safely.

What do these three speeds control?

Pen down changes drawing speed. Pen up changes how quickly the head travels between strokes. Pen lift / lower changes how quickly the tool moves onto and away from the material.

What is this short pause for?

Leave this at the default unless the head starts moving sideways before the pen has fully lifted or touched the material. Increase the pause if that happens. Reduce it only if every lift and touch-down feels unnecessarily slow.

How do I set the pen-tip offset?

Measure the pen tip from the nozzle. X is the left/right difference; Y is the front/back difference. If the pen sits in front of the nozzle, Y is negative. −25 mm Y is a useful starting point for many A1 holders, but use your own measurement when you can.

What happens after homing?

Keep the pen removed while the printer homes and measures the bed. BambuPlot then moves the head to the front edge and waits so you can attach the pen before drawing starts.

Why are Bambu pen changes timed?

These waits are timed because Bambu’s normal Resume pause can enter filament-handling behaviour instead of staying where BambuPlot needs it. On A1 testing it moved toward the cleaning area and could involve heater or filament actions. For multicolour work, the numbered pen-pass ZIP gives you a fresh setup wait before every pen.

When you need to attach or change a pen, BambuPlot lifts the head and moves it to the front edge so the pen is close to you. After drawing alignment crosses, it moves to the back edge so you can reach the bed and place your material on the marks.

seconds

Timed mode gives you the chosen number of seconds to attach a pen or place material, then drawing continues automatically. Set a time that lets you work without rushing.

Do I need arc moves?

Leave this off unless you know your custom printer supports G2/G3 arc moves. Turning it on can make curved G-code smaller; ordinary G1 moves are the safer choice when you are unsure.

My dry run is flipped. What should I do?

If the dry run moves left when the preview moves right, use Mirror X. If front/back is reversed, use Mirror Y. Regenerate the G-code after changing it.

Do I need to save a profile?

You do not need to save a profile for normal use; BambuPlot already remembers these settings in this browser. Save one when you want a backup or want to move your printer, drawing tool, theme and handwriting setup to another browser or device.

First plot? Safe setup & run order
  1. Generate & save. Generate the G-code, download the .gcode file, then copy it to the printer's microSD card.
  2. Prepare the bed. Place your paper/material on the bed and hold it with low-profile magnets. Keep the magnets outside the drawing and toolhead paths.
  3. Start the plot with the pen removed. The printer must home and measure the bed before the pen is attached.
  4. Fit the pen at the front edge. For thin paper, start with the tip about 0.5 mm below the nozzle. You want gentle contact, not pressure. Continue when ready.
  5. Place your material. After the corner crosses are drawn, the head moves to the back edge so you can reach the bed. Line up your material with the marks and secure it with magnets. Continue when ready.
  6. Using one multicolour file? When BambuPlot finishes one colour, it lifts the pen and moves to the front edge. Swap to the next pen during the colour-change wait, and leave the material exactly where it is. Do not move the material.
  7. Using the numbered pen-pass ZIP? (recommended) Run the files in number order. After each pass, leave the material and magnets exactly where they are and remove the pen. Start the next file with no pen attached. The printer homes and measures the bed again, then BambuPlot moves to the front edge and waits for you to attach the next listed pen before drawing.
